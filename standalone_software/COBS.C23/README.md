# COBS test programs
A bunch of libraries that implement [Consistend Overhead Byte Stuffing](https://en.wikipedia.org/wiki/Consistent_Overhead_Byte_Stuffing) framing. Playing here with various API's to see what suits me.
## build instructions
To build: ```make```
To cleanup: ```make clean```
To execute ```make run```
To run clang-tidy ```make check```
